# Recursos do produto

Os modelos Branco, Caderno azul e Jardim da turma são composições vetoriais originais do OKAMI Memórias Escolares, definidas em `src/okami_memorias/decoration.py`. Os fundos, molduras e faixas fazem parte do código do projeto e dispensam recursos gráficos de terceiros. A fonte do título, fornecida pelo ReportLab, está registrada em [licenças de terceiros](../docs/THIRD_PARTY_LICENSES.md).

Registre autor, origem e licença junto de cada novo recurso. Use apenas recursos próprios ou redistribuíveis e mantenha fotografias escolares fora do repositório.
